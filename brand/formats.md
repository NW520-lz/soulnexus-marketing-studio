# 格式卡

每条内容都套一张卡。卡片固定结构、钩子句式和录制清单，每天只换选题和提示词，录制和剪辑都按同一套走。
「成绩」由 `mkt-retro` 在每条复盘后更新；周复盘时淘汰中位数据最差、又没有改进思路的卡，也可以新增卡。

常驻角色放在 `brand/cast/<角色>/`（三视图原图 + 设定说明）。连载和续集直接复用，不重新生成，省钱，也顺便证明角色一致。

---

## F1 制作过程（Made my own version）

- **用途**：展示一集是怎么在画布上做出来的，转化最直接。适合借当周热门的 AI 视频格式。
- **时长**：30–40 秒。**平台**：TikTok / Reels / Shorts 同片，X 拆成 4 条串推。
- **钩子句式**：
  - `Saw this viral <thing>. Made my own version.`
  - `Everyone's posting this <thing>. Here's my twist.`
  - 先闪 1 秒成片高光，再接：`This took one canvas.`
- **结构**：

| 时间 | 画面 | 素材文件 |
|---|---|---|
| 0–3s | 钩子：手机刷到热门格式（屏幕虚焦）或成片高光 + 钩子卡 | `01-hook.mp4` |
| 3–6s | 录屏：打开画布 / 新建画布 | `02-canvas.mp4` |
| 6–15s | 录屏：参考图 → 角色三视图出来 | `03-sheets.mp4` |
| 15–20s | 录屏：agent 写提示词、建视频节点、点生成 | `04-agent.mp4` |
| 20–35s | 成片完整播放 | `05-final.mp4` |
| 最后 2.5s | CTA 卡 | — |

- **录制清单模板**：`01-hook.mp4`（出镜或成片片段，竖屏 4–6s）、`02-canvas.mp4`（录屏 5–10s）、`03-sheets.mp4`（录屏 20–60s）、`04-agent.mp4`（录屏 20–60s）、`05-final.mp4`（工作台成片原文件）。
- **成绩**：

| 日期 | 选题 | TikTok 24h | 72h | 完播率 | 意向评论 | 备注 |
|---|---|---|---|---|---|---|
| 2026-10-27 | 骑士小猫 remix | | | | | 首条，新号 0 粉 |

## F2 痛点对比（Without vs With）

- **用途**：直接打创作者的痛点（角色变脸、失败扣钱、提示词不会写），证明一个具体功能。
- **时长**：20–30 秒。**平台**：TikTok / Reels / Shorts；X 发对比图 + 串推效果更好。
- **钩子句式**：
  - `Why your AI <character> keeps changing`
  - `Same prompt. One setting changed.`
  - `Stop re-generating the whole episode.`
- **结构**：

| 时间 | 画面 | 素材文件 |
|---|---|---|
| 0–3s | 左右分屏：不锁定（变脸）vs 锁定（一致）+ 钩子卡 | `01-without.mp4` + `02-with.mp4`（剪辑时拼） |
| 3–12s | "不锁定"版本连续 3 镜，角色每镜都不一样 | `01-without.mp4` |
| 12–22s | 录屏：功能怎么用（三视图连到每个镜头 / 单镜重拍 / 提示词优化） | `03-how.mp4` |
| 22–28s | "锁定"版本连续 3 镜，角色一致 | `02-with.mp4` |
| 最后 2.5s | CTA 卡 | — |

- **录制清单模板**：`01-without.mp4`（工作台成片，不锁定）、`02-with.mp4`（工作台成片，锁定）、`03-how.mp4`（录屏 10–20s）。
- **成绩**：

| 日期 | 选题 | TikTok 24h | 72h | 完播率 | 意向评论 | 备注 |
|---|---|---|---|---|---|---|

## F3 角色连载（Episode N）

- **用途**：常驻角色的短剧连载，用户不用录屏，制作最快；让账号有可追的内容。每集结尾留悬念。
- **时长**：15–30 秒，几乎全是成片。**平台**：TikTok / Reels / Shorts；X 发成片 + 一句话。
- **钩子句式**：
  - 直接从冲突最强的一镜开始，屏幕字 `Ep <N>: <一句冲突>`
  - `He was told to guard the cliff. Then the dragon woke up.`
  - 结尾屏幕字：`Part <N+1>?`
- **结构**：

| 时间 | 画面 | 素材文件 |
|---|---|---|
| 0–3s | 冲突最强的一镜 + 钩子卡 | `01-ep.mp4` 开头 |
| 3–25s | 成片（1–2 段 15 秒拼接） | `01-ep.mp4`、`02-ep.mp4` |
| 最后 2.5s | CTA 卡（标题改成 `Made on one AI canvas`） | — |

- **常驻角色**：`brand/cast/sir-mochi/`（灰色虎斑小猫骑士、青色围巾）+ 石头龙。
- **录制清单模板**：`01-ep.mp4`（工作台成片 15s）、`02-ep.mp4`（可选，第二段 15s）。没有录屏。
- **出片要求**：视频节点必须连上 cast 里的三视图，9:16，设置按模型核对（10-27 那条因为默认 6 秒横屏，猫跑偏了）。
- **成绩**：

## F4 成本 / 模型对比（X 优先）
