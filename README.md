# SoulNexus Marketing Studio

一个面向 SoulNexus 的本地营销工作台，用 Claude Code / Codex 协助进行选题、录屏素材管理、视频剪辑、字幕包装与发布前审阅。项目包含工作台页面、Python 脚本、品牌模板和 Claude skills。

## 启动工作台

需要 Python 3 和 FFmpeg（剪辑时还需要 ffprobe）。在项目目录执行：

```powershell
python scripts/studio.py serve
```

打开 http://127.0.0.1:5280。按任务需要另行安装脚本依赖；视频包装可能需要 Node.js 和 HyperFrames。语音及转录功能使用的服务、模型和依赖请查看对应脚本说明；外部服务可能收费。

## 目录

- `studio/`：本地工作台页面。
- `scripts/`：工作台、剪辑、转录、配音及视频包装脚本。
- `.claude/skills/`：营销工作流及视频制作相关 skills。
- `brand/`：内容流程、选题规则、品牌和动画模板。
- `tutorial_edit/`：一次教程视频的剪辑脚本示例，原始素材及输出未随仓库提供。

操作流程见 `CLAUDE.md`。该文件及 skills 包含原工作环境路径和个人工作流设置，新环境需要自行调整。部分私有工作配置和素材不包含在仓库内，不能假定克隆后所有流程开箱即用。

## 本地数据

出于隐私和仓库体积考虑，密钥、账户配置、活动资料、录屏、成片、每日工作记录和本地虚拟环境未上传。请在本地自行配置，并在发布或共享前检查素材及授权。使用前确认各第三方工具与素材的使用条款。
